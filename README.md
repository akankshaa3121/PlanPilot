# PlanPilot

Smart event planner for first-time organizers (clubs, families, teams).

**Live app:** # PlanPilot

Smart event planner for first-time organizers (clubs, families, teams).

**Live app:** https://planpilot-1-ork0.onrender.com
(Free hosting: the first load can take up to a minute.)

## Problem
First-time event organizers struggle to plan around a budget, deadlines and vendors, so things get missed at the last minute.

## What PlanPilot does
- Budget split across categories, with a chart where you can select several categories at once
- Backward countdown timeline from the event date
- Vendor checklist with 3 questions to ask each vendor type
- 5 personalized creative ideas
- "What If?" crisis lab that rewrites the plan (rain, caterer cancels, budget cut, fewer guests)
- Readiness Score that updates as tasks are ticked
- Track Spending with 80% budget alerts
- "Done, Finish My Plan" summary with copy and print options

## Built with
Google AI Studio and the Gemini API (React, TypeScript, Express).
